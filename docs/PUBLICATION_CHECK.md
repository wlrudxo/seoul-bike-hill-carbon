# 공개 전 검사 기록

2026-10-12 기준. 대상: `seoul-bike-hill-carbon` 공개 준비. 이 작업에서는 원격 생성·push를 하지 않았다.

## 포함·제외

- 포함: 분석·자료 취득 코드, 보고서 그림 1–5 및 표 1–2 생성 코드, 통합 재현 명령, 경로 설정, 고정 requirements, README, 코드 MIT LICENSE, 공개 검사기, 이 검사 기록.
- 제외: 원본 이력·대여소·DEM·배출계수·경계, 개별 이용/자전거 기록, 중간 집계, 생성 그림·PDF·HWPX, 공모전 양식·신청서·제출자 개인정보, 환경·비밀 설정, 원래 Git 이력 보관 사본.
- `.gitignore`에서 원본·출력 폴더, 표·그림·압축/공간 자료, 환경·캐시·키 파일·Git bundle을 제외한다. 출처·라이선스·해시는 데이터 자체와 구별되는 작은 메타데이터다.

## 이력·공개 검사

기존 두 커밋에도 로컬 절대경로가 있어, 커밋 순서·작성자·시각·메시지를 유지하고 해당 문자열을 상대경로로 바꿔 이력을 재구성했다. **기존 커밋 SHA가 변경되었다.** 원래 Git 데이터베이스의 완전한 사본은 저장소 밖 비공개 작업영역에 보관하고 `git fsck --full`로 확인했다. 공개할 Git 데이터베이스에는 과거 경로가 든 객체·reflog·백업 참조를 가져오지 않았다.

`audit_public.py`는 현재 트리뿐 아니라 모든 저장된 Git 객체와 전체 참조의 커밋을 검사한다. 정리 후 비밀값 패턴·로컬 절대경로·원본/생성 파일·1MiB 초과 객체 검사에서 발견 사항이 없다. 의심 문자열 자체는 출력하지 않는다. 커밋 작성자 이름·이메일은 통상적인 Git 메타데이터로 유지했다.

검사 명령:

```powershell
python audit_public.py
git fsck --full
git diff --check
git status --short
```

## 깨끗한 환경 재현

- 기존 환경과 별도로 Python **3.12.10** 가상환경을 새로 만들고 `requirements.lock.txt`의 35개 패키지를 설치했다. `requirements.txt`도 같은 파일을 참조한다.
- 로컬 원본을 읽되 **빈 출력 폴더, 기존 분석 캐시 없음** 상태에서 `python reproduce.py --raw 입력폴더 --work 새작업폴더`를 실행했다.
- 자료 집계 → 회귀 → 강건성 → 월별 최소비용 수송 → 비대여기간 이동 추정 → 결과 문서 → 12cm 폭 그림 → 요약 그림 → 표/수치 검증을 모두 통과했다. 소요 **461.72초(약 7분 42초)**.
- 그림 1–5 PNG 모두 300dpi. 보고서 편집에 사용한 12cm 폭판 원본 PNG와 **5장 모두 크기·RGB 픽셀이 완전히 일치**했다.
- 표 1의 6개 출처·시점을 코드로 내보냈다. 표 2의 월별 대수·거리·오르막 보충 및 합계가 보고서와 일치했다. 계수·OD 비·탄소·비대여기간 이동 핵심 수치를 계산값에서 따로 검증했다.

| 원본 / 필터 후 통행 | 9,761,201 / 9,427,594 |

증거 파일은 재현 작업 폴더의 `reproduction_run.json`, `report/tables/verification.json`, `report/tables/report_numbers.json`, `report/tables/input_manifest.json`에 생성된다. 원본 그림 비교 및 전체 이력 검사 결과는 비공개 검증 작업영역에 보관했다. 생성 산출물은 Git에 넣지 않는다.

## 남은 한계

외부 다운로드 URL·파일 및 OSM 현행 경계는 앞으로 달라지거나 제공이 중단될 수 있다. 정확한 지도 재현에는 같은 경계 스냅샷과 DEM이 필요하며 취득 메타데이터·해시로 확인한다. 다른 OS나 글꼴 버전에서는 그림 픽셀이 달라질 수 있다. 최소비용 흐름에 여러 최적해가 있으면 솔버 버전에 따라 개별 OD 흐름이 달라질 수 있어 환경 버전을 고정했다. 자동 비밀값 검사는 알려진 패턴 중심이며 완전한 보증은 아니다. 탄소는 공개 대리계수와 운행 가정에 따른 조건부 모형 추정이다.
